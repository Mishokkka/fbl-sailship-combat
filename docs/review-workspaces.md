# Проверка CodeRabbit в PR #2

Проверены [основное ревью](https://github.com/Mishokkka/fbl-sailship-combat/pull/2#pullrequestreview-5415255766) и [архитектурная сводка](https://github.com/Mishokkka/fbl-sailship-combat/pull/2#issuecomment-5994953811).

| Замечание | Вывод и исправление |
| --- | --- |
| [Нормализованные значения фона не видны после сохранения](https://github.com/Mishokkka/fbl-sailship-combat/pull/2#discussion_r4184544650) | Подтверждено. Форма получает сохранённые значения и обновляет контекст. Пустой размер плитки после применения показывает 512. |
| [Изменение структуры существа сохраняет другие поля](https://github.com/Mishokkka/fbl-sailship-combat/pull/2#discussion_r4184544663) | Подтверждено. Структурные команды меняют только секции, атаки или способности. Другие поля сохраняются только явным применением; их черновики не сбрасываются. Мгновенное выполнение структурных команд подписано в редакторе. |
| Тест пресета обходит обработчик приложения | Подтверждено. Проверка нажимает кнопку приложения, вызывает настоящий обработчик и строит новый контекст/шаблон из состояния тестового хранилища. |
| Отказ в записи у неавторитетного ГМа выглядит успешным | Подтверждено. Принятие настроек фона зависит от результата записи: ID боя, новой ревизии и нормализованных значений. Отказ до или после мутации не очищает черновики и не сообщает об успехе. |
| Загрузка фонового изображения при выключенном показе | Подтверждено назначение CSS-ссылки даже при выключенном флажке. Теперь выключенный предпросмотр не назначает изображение. Утечка полномочий или выполнение кода ревью не доказаны; политика URL сохранённых ресурсов не изменялась. |

Проверка настоящего действия применения дополнительно обнаружила потерю данных существа: редактор очищал объект, который нормализатор уже изменил на месте. Удалено повторное очищение; отдельный Node.js тест проверяет сохранение ID, типа, команды, анатомии и атак после редактирования имени.

Рекомендация CodeRabbit о проценте docstring относится к документации, а не к подтверждённому дефекту поведения. Добавлены пояснения к нормализации, подтверждению записи, структурным действиям и браузерной проверке; массовые комментарии ради числового порога не добавлялись.

Проверки находятся в `tests/review-regressions.test.js`, `tools/preview-workspaces.mjs` и `tools/workspace-actions.mjs`. Дополнительно проверяется сохранение новых правок, введённых во время ожидающей записи фона. Хранилище и оболочка Foundry в браузерном стенде подменены; FilePicker, звук и синхронизация живых клиентов требуют проверки в установленном Foundry.
