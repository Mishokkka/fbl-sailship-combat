## Первый этап интерфейса

Общие цвета, типографика, кнопки, поля и клавиатурный фокус применены к окнам модуля. Основное окно получило подсказку текущего действия, подписи переходов, объяснения приказов, раскрываемые подробности и читаемую сводку.

В карточке выстрела собраны цель, шанс, урон при попадании до брони, боеприпас, режим и действие. Отложенный залп подписан как подготовка, без обещания выстрела сейчас. Все батареи доступны в отдельном раскрываемом блоке. Подробности сохраняют открытое/закрытое состояние при обновлении частей окна.

На узком окне используются вкладки поля, флота и управления; завершение активации доступно и в управлении. Подсказки различают ведущего, игрока, чужой контакт, существ, обязательное движение и завершённый бой.

## Проверка в GitHub

- `check`: синтаксис, JSON, импорты, манифест, локализации и Node.js regression suite.
- `interface`: компиляция всех Handlebars-шаблонов, настоящий контекст боевого окна и Chromium. Шесть фаз проверяются на ширинах 1500, 1100 и 800 пикселей.
- Проверяются горизонтальное переполнение, навигация узкого окна, доступность завершения действия, связь боеприпаса с ID батареи и сохранение раскрываемых блоков при замене панели.
- Артефакт `interface-preview` в запуске Actions содержит PNG и HTML. HTML можно открыть для просмотра фаз и переключения вкладок; боевые команды в этом предпросмотре не выполняются.

Предпросмотр использует минимальную оболочку Foundry и демонстрационный бой. Перед выпуском остаётся интеграционная проверка в Foundry VTT 13: обновление между двумя клиентами, поведение в установленной теме, действия из карточек и восстановление сохранений. Автотесты не заменяют эту проверку.
