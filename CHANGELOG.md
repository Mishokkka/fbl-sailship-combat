# Changelog

## Unreleased

### Интерфейс

- Верфь: общая навигация, поиск по каталогам и выбранный участник всегда под рукой.
- Редакторы кораблей и существ разбиты на разделы; кнопки применения и отмены остаются внизу окна. Правки сохраняются между разделами, участниками и обновлениями, пока окно открыто.
- Подготовка боя разделена на поле, команды, условия победы, обзор и сценарии. Поля прорыва показываются только для соответствующей цели.
- Настройки звука и фона оформлены в общем стиле; громкость показана в процентах, фон обновляется в предпросмотре.
- Добавлены браузерные проверки навигации, поиска, черновиков, заблокированных форм и узких окон остальных разделов модуля.

- Общие цвета, кнопки, поля ввода и фокус клавиатуры для окон модуля; обновлено основное окно боя.
- Контекстная подсказка текущего действия, подписи завершения активации и перехода фазы; переход недоступен, пока действуют участники.
- Приказы с краткими объяснениями; подробные расчёты залпа, очередь и особые манёвры раскрываются по требованию.
- Состояние раскрываемых блоков сохраняется при обновлении окна. В узком окне завершение действия доступно на вкладке управления.
- Удалены повторные кнопки залпа; прогноз обозначен как урон при попадании до брони, подготовка залпа подписана отдельно.

### Исправления ревью

- Структурные команды редактора существ больше не сохраняют остальные незавершённые правки; исправлена потеря данных при нормализации после явного применения.
- Настройки фона показывают нормализованные сохранённые значения, сохраняют черновик при отказе/ошибке записи и не теряют правки, введённые во время ожидания. Выключенный предпросмотр не загружает изображение.
- Браузерные регрессии теперь вызывают настоящие действия подготовки и редакторов через тестовое хранилище.

- Проверки чисел и границ поля, запрет отложенных правок состава после старта боя, безопасные селекторы редактора.
- Исправлены буксировка, столкновения с существами, вертикальные манёвры ИИ, ядра в морском режиме и расход действий при безрезультатном торможении.
- Сохранения используют общую очередь; сокеты используют серверное время; исчезнувший выбранный корабль не подменяется другим в Верфи.
- Добавлены регрессионные тесты, проверки подсказок и CI с предпросмотрами настоящих шаблонов в Chromium.

## 0.14.2

### Несколько команд

- Исправлен неработающий выпадающий список команды выбранной единицы в Верфи: для нативного `select` добавлен отдельный обработчик `change`.
- В Верфи добавлен постоянный выбор команды для новых кораблей и существ на всех вкладках.
- Текущий состав боя теперь сгруппирован по командам с отдельными цветами, счётчиками кораблей, существ и боеспособных единиц.
- Новые, импортированные и библиотечные корабли и существа помещаются в явно выбранную команду и её зону расстановки.
- Смена команды существующей единицы переносит её в зону новой команды.
- Команды можно добавлять прямо из Верфи; названия, цвета и зоны редактируются в окне подготовки.
- Непустую команду больше нельзя удалить с молчаливым переносом участников в другую сторону.

### Правила и поле боя

- Стрельба кораблей, атаки существ и видимость проверены для двух независимых противников одновременно.
- Условие уничтожения теперь корректно ждёт, пока боеспособной останется только одна из трёх и более команд.
- Провал прорыва при нескольких независимых защитниках больше не назначает победителем первую команду в массиве.
- Генератор поля расчищает каждой команде проход от зоны расстановки к центру, не оставляя одну из сторон запертой скалами или островами.
- В окне подготовки команды показывают число кораблей и существ; терминология интерфейса приведена к единому слову «команда».

### Тесты

- Добавлены регрессионные сценарии для боя «два корабля и чудовище» с тремя независимыми командами.
- Проверены создание и размещение, артиллерийские цели, естественные атаки, видимость, победа, удаление команд и генерация террейна.
- Общий набор расширен до 63 автоматических тестов.

## 0.14.1

### Миграции

- Схема активного боя теперь проходит последовательную цепочку миграций от v0 до v13.
- Добавлена явная ошибка для данных из более новой, неподдерживаемой версии схемы.
- Миграции сделаны идемпотентными и покрыты тестами для каждой исходной версии.
- Сохранения, библиотека кораблей, бестиарий и сценарии получили собственную версию коллекции и автоматическую миграцию.
- Сохранено старое тактическое состояние вооружения при переходе на исторические батареи.

### Исправления

- Смешанные пользовательские сценарии больше не пропускают летающих существ через нормализатор корабля и не теряют `unitType` и `creatureType`.
- Загрузка неизвестного ID сохранения подтверждена регрессионным тестом и не откатывается к последнему сохранению.
- Конфликт revision подтверждён тестом: случайная мутация выполняется ровно один раз и не перебрасывается автоматически.

### Диагностика

- Добавлен `game.sailshipsCombat.runDiagnostics()` для проверки состояния документного хранилища, прав, схем, проекций и старых world settings.
- В API доступен `game.sailshipsCombat.diagnostics`.

### Разработка

- Добавлен автономный Node.js test suite без внешних зависимостей.
- Добавлены команды `npm test`, `npm run check:module` и `npm run check`.
- Набор содержит 55 автоматических тестов боевых движков, миграций, хранилища, сокетов и диагностики.
